# Datavaura website

Renewal of [datavaura.com](https://datavaura.com) — enterprise technology, integration, and UAE digital compliance.

## Brand

- Ink / navy, desert gold, aurora teal, warm sand paper
- Instrument Serif + Geist Sans + Geist Mono
- CTAs: **Book a Consultation** throughout

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Positioning

Datavaura is not a general IT catalogue. It is the implementation layer between ERP and the digital economy — especially UAE e-invoicing (PINT-AE / Peppol) — without claiming Accredited Service Provider status. Official mandate source: [mof.gov.ae](https://mof.gov.ae).
